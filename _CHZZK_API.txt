# 치지직(Chzzk) 비공식 API 정리

CHZZK에서 사용 중인 비공식 API 중 일부를 정리합니다.

---

## 1. 현재 시청자 수 최고 게임 (인기 카테고리 목록)

### 개요
시청자 수 기준으로 정렬된 게임 카테고리 목록을 반환합니다.

### 요청 정보

| 항목 | 내용 |
|------|------|
| **Method** | GET |
| **Base URL** | `https://api.chzzk.naver.com/service/v1/categories/live` |

### 쿼리 파라미터

| 파라미터 | 타입 | 필수 | 설명 |
|----------|------|------|------|
| categoryType | string | O | `GAME` (고정) |
| size | number | O | 반환할 게임 개수 (최대 50) |

### 예시 URL
```
https://api.chzzk.naver.com/service/v1/categories/live?categoryType=GAME&size=50
```

### 응답 데이터 (아이템별)

| 필드 | 타입 | 설명 |
|------|------|------|
| categoryType | string | `"GAME"` |
| categoryId | string | 카테고리 ID (영문 슬러그, 예: `Minecraft`) |
| categoryValue | string | 카테고리 한글명 (예: `마인크래프트`) |
| posterImageUrl | string | 포스터 이미지 URL |
| openLiveCount | number | 현재 진행 중인 라이브 개수 |
| concurrentUserCount | number | 총 시청자 수 |
| newCategory | boolean | 신규 카테고리 여부 |
| dropsCampaignNos | array | 드롭스 캠페인 ID 목록 |

### 응답 예시
```json
{
  "categoryType": "GAME",
  "categoryId": "Minecraft",
  "categoryValue": "마인크래프트",
  "posterImageUrl": "https://nng-phinf.pstatic.net/...",
  "openLiveCount": 110,
  "concurrentUserCount": 43013,
  "newCategory": false,
  "dropsCampaignNos": []
}
```

## 2. 특정 카테고리 라이브 목록

### 개요
특정 게임 카테고리의 실시간 방송 목록을 반환합니다. (약 20개까지)

### 요청 정보

| 항목 | 내용 |
|------|------|
| **Method** | GET |
| **Base URL** | `https://api.chzzk.naver.com/service/v2/categories/{categoryType}/{slug}/lives` |

### 경로 파라미터

| 파라미터 | 설명 |
|----------|------|
| categoryType | 카테고리 종류 (우리는 `GAME`만 사용) |
| slug | 게임 슬러그 (예: `Minecraft`, `League_of_Legends`) |

### 예시 URL
```
https://api.chzzk.naver.com/service/v2/categories/GAME/Minecraft/lives
```

### 응답 데이터 (아이템별)

| 필드 | 타입 | 설명 |
|------|------|------|
| liveId | number | 라이브 고유 ID |
| liveTitle | string | 방송 제목 |
| liveImageUrl | string | 썸네일 URL (`{type}` → 480, 720, 1080 등으로 치환) |
| defaultThumbnailImageUrl | string \| null | 기본 썸네일 URL |
| concurrentUserCount | number | 시청자 수 |
| cvExposure | boolean | 시청자 수 노출 여부 |
| accumulateCount | number | 누적 시청자 수 |
| openDate | string | 방송 시작일시 |
| adult | boolean | 성인 콘텐츠 여부 |
| tags | string[] | 태그 목록 |
| categoryType | string | `"GAME"` |
| liveCategory | string | 게임 영문 슬러그 |
| liveCategoryValue | string | 게임 한글명 |
| channel | object | 채널 정보 |

### channel 객체

| 필드 | 타입 | 설명 |
|------|------|------|
| channelId | string | 채널 ID |
| channelName | string | 채널명 |
| channelImageUrl | string | 채널 프로필 이미지 URL |
| verifiedMark | boolean | 인증 마크 여부 |
| activatedChannelBadgeIds | string[] | 활성화된 배지 ID 목록 |

### 응답 예시
```json
{
  "liveId": 17527246,
  "liveTitle": "[픽크타2] 어제 하루 통으로 쉬었는데 저 개10도태녀인가요?",
  "liveImageUrl": "https://livecloud-thumb.akamaized.net/.../image_{type}.jpg",
  "defaultThumbnailImageUrl": null,
  "concurrentUserCount": 4717,
  "cvExposure": true,
  "accumulateCount": 0,
  "openDate": "2026-02-27 13:29:44",
  "adult": false,
  "tags": ["스텔라이브", "타비", "버튜버", "픽크타2"],
  "categoryType": "GAME",
  "liveCategory": "Minecraft",
  "liveCategoryValue": "마인크래프트",
  "channel": {
    "channelId": "a6c4ddb09cdb160478996007bff35296",
    "channelName": "아라하시 타비",
    "channelImageUrl": "https://nng-phinf.pstatic.net/...",
```

## 3. 특정 카테고리 라이브 목록 (페이지네이션) ⚠️ 사용 비권장

### 개요
특정 시청자 수 이상의 라이브만 필터링하거나, 특정 liveId 이후 목록을 이어서 가져오는 API로 추정됩니다. **확실한 정보가 아니므로 사용하지 말 것.**

### 요청 정보

| 항목 | 내용 |
|------|------|
| **Method** | GET |
| **Base URL** | `https://api.chzzk.naver.com/service/v2/categories/GAME/{slug}/lives` |

### 쿼리 파라미터

| 파라미터 | 설명 |
|----------|------|
| concurrentUserCount | 특정 시청자 수 이상인 라이브만 표시 |
| liveId | 해당 라이브 ID 이후 목록을 이어서 표시 |

### 예시 URL
```
https://api.chzzk.naver.com/service/v2/categories/GAME/Black_Survival_Eternal_Return/lives?concurrentUserCount=14&liveId=17529398
```

### 응답 데이터
→ [2. 특정 카테고리 라이브 목록]과 동일한 구조

## 4. 특정 카테고리 다시보기 목록 (VOD)

### 개요
특정 게임 카테고리의 다시보기(VOD) 목록을 반환합니다.

### 요청 정보

| 항목 | 내용 |
|------|------|
| **Method** | GET |
| **Base URL** | `https://api.chzzk.naver.com/service/v2/categories/GAME/{slug}/videos` |

### 경로 파라미터

| 파라미터 | 설명 |
|----------|------|
| slug | 게임 슬러그 |

### 쿼리 파라미터 (추정)

| 파라미터 | 설명 |
|----------|------|
| size | 반환 개수 |
| offset | 페이지네이션 오프셋 |

### 예시 URL
```
https://api.chzzk.naver.com/service/v2/categories/GAME/Minecraft/videos
```

### 응답 데이터 (아이템별)

| 필드 | 타입 | 설명 |
|------|------|------|
| videoNo | number | 영상 번호 |
| videoId | string | 영상 고유 ID (URL에 사용) |
| videoTitle | string | 영상 제목 |
| videoType | string | `REPLAY` 등 |
| publishDate | string | 공개일시 |
| publishDateAt | number | 공개일시 (Unix ms) |
| thumbnailImageUrl | string | 썸네일 URL |
| trailerUrl | string \| null | 예고편 URL |
| duration | number | 재생 시간 (초) |
| readCount | number | 조회수 |
| videoCategory | string | 게임 영문 슬러그 |
| videoCategoryValue | string | 게임 한글명 |
| livePv | number | 라이브 시청자 수 |
| tags | string[] | 태그 목록 |
| channel | object | 채널 정보 |

## 7. 특정 게임 카테고리 클립 목록

### 개요
특정 게임의 인기 클립 목록을 반환합니다. (최근 30일 이내, 시청자순)

### 요청 정보

| 항목 | 내용 |
|------|------|
| **Method** | GET |
| **Base URL** | `https://api.chzzk.naver.com/service/v1/categories/GAME/{slug}/clips` |

### 경로 파라미터

| 파라미터 | 설명 |
|----------|------|
| slug | 게임 슬러그 |

### 쿼리 파라미터

| 파라미터 | 타입 | 필수 | 설명 |
|----------|------|------|------|
| filterType | string | O | `WITHIN_THIRTY_DAYS` (최근 30일), `WITHIN_SEVEN_DAYS` (최근 7일), `WITHIN_ONE_DAY` (최근 24시간), 'ALL' (전체) |
| orderType | string | O | `POPULAR` (시청자순), 'RECENT' (최신순) |
| size | number | O | 반환할 클립 개수 (최대 50) |

### 예시 URL
```
https://api.chzzk.naver.com/service/v1/categories/GAME/Minecraft/clips?filterType=WITHIN_THIRTY_DAYS&orderType=POPULAR&size=10
```

### 응답 데이터 (아이템별)

| 필드 | 타입 | 설명 |
|------|------|------|
| clipUID | string | 클립 고유 ID |
| videoId | string | 영상 ID |
| clipTitle | string | 클립 제목 |
| ownerChannelId | string | 업로더 채널 ID |
| ownerChannel | object | 업로더 채널 정보 |
| thumbnailImageUrl | string | 썸네일 URL |
| clipCategory | string | 게임 영문 슬러그 |
| duration | number | 재생 시간 (초) |
| adult | boolean | 성인 콘텐츠 여부 |
| createdDate | string | 생성일시 |
| readCount | number | 조회수 |

### 응답 예시
```json
{
  "clipUID": "L1AKEHL3p7",
  "videoId": "E6F0A0D13ADFA1C4867208201DA813466943",
  "clipTitle": "최신기술 터미널 ㅋㅋ",
  "ownerChannelId": "bdc57cc4217173f0e89f63fba2f1c6e5",
```

## 9. 특정 라이브 정보 (채널별 상세)

### 개요
특정 채널의 라이브 방송 상세 정보를 반환합니다. 스트리밍 URL(HLS), 채팅 채널 ID 등 포함.

### 요청 정보

| 항목 | 내용 |
|------|------|
| **Method** | GET |
| **Base URL** | `https://api.chzzk.naver.com/service/v3.3/channels/{channelId}/live-detail` |

### 경로 파라미터

| 파라미터 | 설명 |
|----------|------|
| channelId | 채널 ID (예: `https://chzzk.naver.com/live/{channelId}`) |

### 쿼리 파라미터

| 파라미터 | 설명 |
|----------|------|
| cu | (미확인) |
| dt | (미확인) |
| tm | `true` (타임머신 관련) |

### 예시 URL
```
https://api.chzzk.naver.com/service/v3.3/channels/9351fb8417f73405c84e0846409e3263/live-detail?cu=false&dt=6998e&tm=true
```

### 응답 구조 (최상위)

| 필드 | 타입 | 설명 |
|------|------|------|
| code | number | 응답 코드 (200 = 성공) |
| message | string \| null | 에러 메시지 |
| content | object | 라이브 상세 데이터 |

### content 주요 필드

| 필드 | 타입 | 설명 |
|------|------|------|
| liveId | number | 라이브 ID |
| liveTitle | string | 방송 제목 |
| status | string | `OPEN`(방송중) / `CLOSE`(종료) |
| liveImageUrl | string | 썸네일 URL (`{type}` 치환 가능) |
| concurrentUserCount | number | 시청자 수 |
| openDate | string | 방송 시작일시 |
| closeDate | string \| null | 방송 종료일시 |
| adult | boolean | 성인 콘텐츠 여부 |
| tags | string[] | 태그 목록 |
| chatChannelId | string | 채팅 채널 ID |
| liveCategory | string | 게임 영문 슬러그 |
| liveCategoryValue | string | 게임 한글명 |
| livePlaybackJson | string | JSON 문자열 (HLS 스트리밍 URL, 인코딩 트랙 등 포함) |
| channel | object | 채널 정보 |

## 공통 사항

### 이미지 URL 치환
- 썸네일 URL에 `{type}` 플레이스홀더가 있는 경우, `480`, `720`, `1080` 등으로 치환하여 해상도 선택 가능

### 참고
- 모든 API는 비공식이며, 변경·중단될 수 있습니다.
- 요청 시 `User-Agent`, `Referer` 등 브라우저 헤더를 설정하는 것이 안정적입니다.
